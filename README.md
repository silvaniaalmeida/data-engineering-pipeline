# Data Engineering Pipeline

Projeto de Engenharia de Dados desenvolvido em Python,
com foco na construção de um pipeline ETL
(Extract, Transform, Load).

## Objetivo

Desenvolver um pipeline para extrair, transformar,
validar e carregar dados, aplicando boas práticas
de Engenharia de Dados e versionamento com Git.

## Tecnologias

- Python
- SQL
- PostgreSQL (etapa futura)
- Git e GitHub

## Estrutura do projeto

- data/ — arquivos de entrada e saída
- src/ — código-fonte do pipeline
- tests/ — testes automatizados
